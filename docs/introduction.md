# Introduction

This project demonstrates the deployment of a cloud-hosted personal portfolio website using Microsoft Azure Infrastructure as a Service (IaaS).

The objective of the project was to create a secure and publicly accessible web server running Ubuntu Server 24.04 LTS. The server hosts a personal portfolio website and is accessible through a DNS name using HTTPS encryption.

The project demonstrates practical skills in:

- Cloud server deployment
- Linux server administration
- Network configuration
- Web server installation and configuration
- DNS management
- SSL/TLS implementation
- GitHub documentation
- Shell scripting

The entire implementation was documented using GitHub to allow the server to be recreated if required.
