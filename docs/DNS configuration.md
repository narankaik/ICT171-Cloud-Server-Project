# DNS Configuration

## Objective

Configure a DNS name so the server can be accessed using a readable domain name instead of only an IP address.

## DNS Entry

```text
clintonportfolio2026.australiaeast.cloudapp.azure.com
```

## Procedure

1. Opened the Azure virtual machine.
2. Selected the public IP address.
3. Opened Configuration.
4. Added a DNS name label.
5. Saved the configuration.

## Verification

The DNS name was tested in a browser:

```text
http://clintonportfolio2026.australiaeast.cloudapp.azure.com
```

The website loaded successfully.
