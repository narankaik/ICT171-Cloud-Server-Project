# Network Security Group Configuration

## Objective

Configure inbound rules to allow remote administration and website access.

## Rules Configured

| Port | Protocol | Purpose |
|--------|-----------|----------|
| 22 | TCP | SSH |
| 80 | TCP | HTTP |
| 443 | TCP | HTTPS |

## Procedure

1. Opened Networking settings.
2. Accessed Network Security Group.
3. Verified inbound rules.
4. Added HTTP rule.
5. Added HTTPS rule.

## Verification

Successfully accessed the server through SSH and web browser.
